📈 Time Series Sales Forecasting

Time Series Analysis

A time series analysis project focused on identifying sales trends, seasonality, and variability in historical sales data and forecasting future monthly sales. Order data was aggregated into monthly sales values for statistical analysis and model development.

Key Features: Exploratory time series analysis, rolling mean and variance analysis, seasonal decomposition, stationarity testing using the Augmented Dickey-Fuller test, and comparison of forecasting models using information criteria and residual diagnostics.

The project compares ARIMA, SARIMA, and Holt–Winters Exponential Smoothing. According to the project evaluation, SARIMA achieved the lowest AIC and BIC values among the evaluated models, with well-behaved residuals.

Technologies: Python, Pandas, NumPy, Matplotlib, Statsmodels, Jupyter Notebook

🌦️ Weather Analysis & Localized Next-Hour Weather Forecasting System

BSc (Hons) Data Science Capstone

A collaborative capstone project focused on historical weather analysis and next-hour weather forecasting using hourly weather data from 2020 to 2025 across five Sri Lankan districts: Colombo, Gampaha, Galle, Kandy, and Jaffna.

The project includes an LSTM-based multi-output forecasting model that uses the previous 24 hours of observations to predict the next hour's weather conditions for Colombo.

Forecasting Variables: Temperature, humidity, pressure, wind speed, rainfall, wind gust, cloud cover, solar radiation, and dew point.

Key Features: Historical weather analysis, geographical point selection, current weather information, next-hour forecasting, model evaluation results, and rain/no-rain performance analysis through a Streamlit dashboard.

The dataset was divided chronologically into training data (2020–2023), validation data (2024), and testing data (2025). The dashboard identifies the nearest predefined Colombo geographical point for forecasting.

Technologies: Python, Pandas, NumPy, Scikit-learn, TensorFlow/Keras, Streamlit, Matplotlib, Seaborn, Open-Meteo API

☁️ ChurnIQ: Enterprise Customer Churn Prediction & Analytics

Group Project · Machine Learning & AWS

An end-to-end cloud-based machine learning and customer analytics solution designed to identify customers at risk of leaving a retail business. The system uses a dataset of 100,000 retail customers and combines predictive analytics, serverless data processing, and interactive business intelligence.

Machine Learning: Compared Logistic Regression, Gradient Boosting, Random Forest, and Extra Trees. The selected Logistic Regression pipeline achieved 94.59% test accuracy and 99.04% ROC-AUC, according to the project's evaluation.

Cloud Data Pipeline: Amazon S3 stores incoming and processed data, AWS Lambda validates uploaded datasets, CloudWatch supports execution monitoring, and Amazon Athena enables SQL-based analytics.

Key Features: Customer churn prediction, churn probability scoring, customer risk visualization, business SQL analytics, automated data validation, and an interactive dashboard with actionable customer retention insights.

Technologies: Python 3.11, Pandas, Scikit-learn, FastAPI, Streamlit, Plotly, AWS S3, AWS Lambda, Amazon CloudWatch, Amazon Athena, Docker
